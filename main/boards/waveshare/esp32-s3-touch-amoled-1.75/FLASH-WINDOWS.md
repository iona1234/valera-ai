# Прошивка Valera — пошагово (новичок)

Плата: **Waveshare ESP32-S3-Touch-AMOLED-1.75**  
Порт: обычно **COM4** (смотрите в Диспетчере устройств).

Весь код Valera лежит здесь:
`main/boards/waveshare/esp32-s3-touch-amoled-1.75/`
- `valera_face.cc` / `valera_face.h` — часы, шторка, настройки
- `esp32-s3-touch-amoled-1.75.cc` — железо, Wi‑Fi `MyWiFi` / `23456789`
- `FLASH-WINDOWS.md` — эта инструкция

---

## 1. Скачать прошивку

1. Откройте:  
   https://github.com/iona1234/valera-ai/actions?query=branch%3Acursor%2Fvalera-amoled-1-75-cb17
2. Войдите в **последний зелёный** run (галочка).
3. Внизу **Artifacts** → скачайте  
   `xiaozhi_waveshare-esp32-s3-touch-amoled-1.75_…`
4. Распакуйте ZIP → файл **`merged-binary.bin`**.

---

## 2. Установить esptool (один раз)

PowerShell:

```powershell
pip install esptool
```

---

## 3. Прошить COM4

Положите `merged-binary.bin` например в `E:\valera\`:

```powershell
cd E:\valera
python -m esptool --chip esp32s3 -p COM4 -b 460800 write_flash 0x0 merged-binary.bin
```

Если не шьётся:
1. Зажмите **BOOT** на плате  
2. Нажмите **RESET** (или переткните USB)  
3. Отпустите **BOOT**  
4. Снова запустите команду выше  

Успех: `Hash of data verified` / `Hard resetting...`

---

## 4. После включения

Экран переписан: в каждый момент видна **одна** страница на весь круг.

1. Если сервер прислал код — сразу полноэкранный **КОД** (OK закрывает). Код также остаётся внизу часов.
2. Wi‑Fi сам цепляется к **MyWiFi** / **23456789** (только **2.4 ГГц**).
3. Свайп влево/вправо: **Часы → Погода → Радио → Станции**.
4. Свайп вниз: **Настройки** (яркость, громкость, кнопка **Код**, Назад).
5. Станции: одна карточка, кнопки **<** **Выбрать** **>** по центру.
6. Радио пока только выбирает станцию. Звук эфира ещё не подключён — на экране так и написано.

Код вводится на https://xiaozhi.me

---

## 5. Если снова «перезагружается»

1. Прошейте **новый** `merged-binary.bin` с последнего зелёного CI (не старый файл).  
2. Кабель USB должен быть **data**, не «только зарядка».  
3. Не держите PWR зажатым (~1.8 с = выключение).
