# Идеи развития Valera (по аналогам на GitHub)

Ориентиры: [PopkaStudio](https://github.com/PopaSpinka/PopkaStudio), XiaoZhi boards, круглые LVGL-часы (SenseCAP Watch / Waveshare demos).

## Уже сделано в этой ветке

- Телефонная шторка с пальцевым pull + пружина ~60 fps
- Темы Modern/Neon/Soft/Retro/Digital
- Локальный wake «Валера»
- Скрытие станций (NVS)
- Процедурное слайд-шоу (без картинок во flash)

## Ближайшие доработки (после железа)

1. **LVGL-экраны Радио / Станции / Громкость** — сейчас полноценны в `ui-preview.html`; на устройстве пресеты + MCP, UI постера — следующий слой.
2. **Декод HTTP-радио + ICY title** — Popka-like marquee «♪ сейчас играет».
3. **Долгий тап × на станции** → `ValeraRadioPrefs::SetHidden` без MCP.
4. **Кроссфейд idle-страниц** (opacity 120–160 мс).
5. **Page dots** внизу idle (как у watchOS).

## Инновации «как у лучших»

| Идея | Зачем | Сложность |
| --- | --- | --- |
| Always-On dim clock | AMOLED экономит, часы видны ночью | средняя |
| Haptic через вибро (если добавить мотор) | «дорогой» отклик на жесты | железо |
| On-device weather glyphs анимированные | вау без сети | низкая |
| SD-карта для плейлиста/слайдов | слот на плате есть | средняя |
| Matter / Home Assistant MCP | умный дом голосом | средняя |
| Offline TTS-фразы | ответ без облака при обрыве | высокая |
| Face ID-стиль «взгляд следит за пальцем» | уже частично в глазах | низкая |
| Gesture tutorial при первом boot | меньше вопросов | низкая |
