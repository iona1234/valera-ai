# Что делать дальше (после Wi‑Fi)

Wi‑Fi уже есть (у вас было `192.168.3.104`). Дальше нужен **облачный мозг** — без него устройство остаётся часами с глазами.

---

## Шаг 1. Перепрошейте свежий билд

Старый образ мог выключаться через ~5 минут и без NTP. Скачайте **новый** `merged-binary.bin` из последнего зелёного CI:

https://github.com/iona1234/valera-ai/actions?query=branch%3Acursor%2Fvalera-amoled-1-75-cb17

```powershell
cd E:\valera
python -m esptool --chip esp32s3 -p COM4 -b 460800 write_flash 0x0 merged-binary.bin
```

Wi‑Fi в NVS сохранится (не делайте `erase_flash`).

---

## Шаг 2. Код берётся с платы (не с Google)

**Адрес сайта:** https://xiaozhi.me — туда **вводят** код.

1. Плата в домашнем Wi‑Fi. На экране должны быть **часы**, не «Подключение…».
2. Если в роутере IP есть, а на экране «Подключение…» — нажмите **RESET** на плате (Wi‑Fi сохранится).
3. После связи с облаком плата **сама** покажет и проговорит код (обычно 6 цифр).
4. На xiaozhi.me → агент «Валера» → добавить устройство → вставьте **этот код**.
5. Снова «Валера» / короткое BOOT — должен отвечать.

IP платы (`192.168.3.x`) в браузере чат **не** открывает.

---

## Что на экране (после этого фикса)

| Было | Стало |
| --- | --- |
| «ЧИСТО» сверху | Пусто, пока нет погоды; потом «−5° ясно» |
| «ЧТ … НВ» | «четверг, 20 ноября» (после NTP) |
| Размытые огромные цифры | Чёткие цифры без zoom |
| Перезагрузка ~каждые 5 мин | Авто-выключение отключено |
| Время 0:05 от включения | SNTP → Барнаул (UTC+7) |

Шторка: серая полоска сверху → тап, или свайп вниз с верхней части экрана.

## Если снова экран настройки Wi‑Fi

Только сеть **2.4 ГГц**. Длинное BOOT (~3 с) — сброс в hotspot `Xiaozhi-XXXX` → http://192.168.4.1
