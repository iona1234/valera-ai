## Код активации (xiaozhi.me)

Код **не** в Google и **не** в роутере. Его даёт **плата** после связи с облаком.

### По шагам

1. Прошейте свежий `merged-binary.bin` (CI зелёный).
2. Питание / RESET. Должны быть **часы** (крупные сегменты), не «Подключение…».
3. Подождите 30–90 с. Плата сходит на `api.tenclass.net` (OTA/активация).
4. На экране появится строка вида **`Код: 123456`** (и цифры проговорят голосом).
5. Откройте **https://xiaozhi.me** → войдите → агент «Валера» → **добавить устройство**.
6. Введите код с экрана платы.
7. Снова скажите **«Валера»** или короткое **BOOT** — должен ответить.

### Если кода нет

| Симптом | Что сделать |
| --- | --- |
| «Подключение…», а в роутере IP есть | RESET; или новая прошивка с фиксом |
| Часы есть, кода нет | Подождите до 2 мин; проверьте интернет (DNS/VPN) |
| Белые вспышки / перезагрузки | Новая прошивка: авто‑OTA с облака отключена |
| Экран ошибки облака | Роутер режет `api.tenclass.net` — нужен доступ в интернет |

Логи (PowerShell):  
`python -m serial.tools.miniterm COM4 115200`  
ищите `activation`, `Activating`, `code`.

IP платы (`192.168.3.x`) в браузере **не** открывает чат.
