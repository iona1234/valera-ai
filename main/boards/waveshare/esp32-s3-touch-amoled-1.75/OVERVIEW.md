# Как устроен проект Valera сейчас

Плата: **Waveshare ESP32-S3-Touch-AMOLED-1.75** (только 1.75).  
Скриншоты экранов: папка `ui-screens/`. Интерактивный превью: `ui-preview.html`.

---

## 1. Структура (что где лежит)

```
valera-ai/                          ← весь XiaoZhi + Valera
├── main/
│   ├── application.*               ← главный цикл, протокол
│   ├── audio/                      ← микрофон, wake «Валера», кодеки
│   ├── boards/
│   │   └── waveshare/
│   │       └── esp32-s3-touch-amoled-1.75/   ← НАША плата
│   │           ├── esp32-s3-touch-amoled-1.75.cc  ← железо: SPI, touch, кнопки, MCP
│   │           ├── valera_face.*                 ← UI лица / часы / шторка / жесты
│   │           ├── valera_radio_stations.h       ← 23 РФ-станции
│   │           ├── valera_radio_prefs.*          ← скрытие станций (NVS)
│   │           ├── valera_sensors.*              ← погода / BME280
│   │           ├── config.h / config.json        ← пины и вариант сборки
│   │           ├── ui-preview.html               ← живой превью в браузере
│   │           ├── ui-screens/*.webp             ← фото всех окон
│   │           ├── SETUP.md                      ← гайд подключения
│   │           ├── OVERVIEW.md                   ← этот файл
│   │           ├── TZ.md / IDEAS.md / README.md
│   ├── protocols/                  ← WebSocket / MQTT к xiaozhi.me
│   └── display/                    ← общие LVGL-виджеты XiaoZhi
├── scripts/build.py                ← сборка платы
└── .github/workflows/              ← CI
```

Коротко: **лицо и жесты** — `valera_face.*`, **кнопки и Wi‑Fi** — `esp32-s3-touch-amoled-1.75.cc`, **мозг в облаке** — xiaozhi.me через `protocols/`.

## 3. Кнопки на плате

На Waveshare 1.75 две кнопки:

| Кнопка | Где | Действие |
| --- | --- | --- |
| **BOOT** короткое | GPIO0 | Старт/стоп разговора (если wake не сработал) |
| **BOOT** длинное ~3 с | GPIO0 | Сброс Wi‑Fi → режим настройки |
| **BOOT** двойное | GPIO0 | Device AEC вкл/выкл (в idle) |
| **PWR** короткое | TCA9554 EXIO4 | Разбудить + громкость +10 (после 100 → 20) |
| **PWR** длинное ~1.8 с | EXIO4 | Мягкое выключение (AXP2101) |
| **PWR** ~4 с | аппаратно | Жёсткое выключение PMIC |

### Жесты на круглом экране

| Жест | Что делает |
| --- | --- |
| Свайп **↓ с верха** | Шторка: яркость, громкость, Wi‑Fi, тема, Always On, сброс Wi‑Fi |
| Свайп **↑** по шторке | Закрыть шторку |
| Свайп **← / →** | Часы ↔ погода ↔ глаза ↔ слайды |
| «**Валера**» | Пробуждение → слушает → думает → отвечает |

## 4. Как подключить (когда приедет плата)

Полный текст: **[SETUP.md](./SETUP.md)**. Краткий чеклист:

1. **Прошить** (ESP-IDF 6.x):
   ```sh
   source ~/esp/esp-idf/export.sh
   python3 scripts/build.py waveshare/esp32-s3-touch-amoled-1.75 \
     --name esp32-s3-touch-amoled-1.75 --language ru-RU
   ```
2. **Wi‑Fi:** точка `Xiaozhi-XXXX` → телефон → http://192.168.4.1 → домашняя сеть.
3. **Сайт:** зарегистрироваться на **https://xiaozhi.me** (бесплатно для личного).
4. Создать агента (русский, часовой пояс Asia/Barnaul).
5. **Привязать** устройство кодом из консоли (сказать «Валера» или BOOT).
6. Готово — можно говорить с Валерой.

Seeed / SenseCraft **не нужны** для wake и консоли — это другой магазин/продукт.
