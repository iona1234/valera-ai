# Первый запуск Валеры · гайд

Плата: **Waveshare ESP32-S3-Touch-AMOLED-1.75** (не 1.75c).  
Корпус уже можно печатать; железо приедет через 1–2 дня.

---

## 1. Что бесплатно, а что нет

| Сервис | Нужно? | Деньги |
| --- | --- | --- |
| [xiaozhi.me](https://xiaozhi.me) (Сиоджи / XiaoZhi) | Да — облачный мозг (голос→ответ) | **Бесплатная** регистрация для личных устройств |
| Seeed / SenseCAP | Нет для Valera | Seeed — магазин железа; **не** биллинг wake |
| Wake «Валера» | Уже в прошивке | **Локально**, без оплаты (`USE_VALERA_RU_LOCAL_EAR`) |
| Облачный STT для wake | Не используем | — |

**Итог:** проект рассчитан на полностью бесплатный личный сценарий.

## 2. Регистрация на xiaozhi.me (пошагово)

1. Откройте **https://xiaozhi.me** (иногда зеркала/региональные входы — берите официальный сайт из README XiaoZhi).
2. Зарегистрируйтесь (телефон / почта / способ, который предлагает форма).
3. Войдите в **консоль** → раздел устройств / агентов.
4. Создайте **агента** (персонаж «Валера»):
   - язык: **русский**;
   - часовой пояс: **Asia/Barnaul** (или ваш);
   - модель: бесплатный realtime (часто Qwen) — смотрите что доступно в личном тарифе.
5. Получите **код привязки устройства** (обычно 6 цифр) или QR — он понадобится после Wi‑Fi.
6. Ничего платить на старте не нужно. Платные квоты появляются только если вы сами включите премиум-модели / много облачного трафика.

> Если сайт просит «Seeed / SenseCraft» — это другой продукт. Для этой прошивки нужна именно консоль **xiaozhi.me**, совместимая с XiaoZhi ESP.

## 3. Прошивка платы (когда приедет)

**Windows / COM-порт:** см. **[FLASH-WINDOWS.md](./FLASH-WINDOWS.md)** (готовая `merged-binary.bin` из CI).


```sh
source /path/to/esp-idf/export.sh   # ESP-IDF ≥ 6.0.1, лучше 6.1
python3 scripts/build.py waveshare/esp32-s3-touch-amoled-1.75 \
  --name esp32-s3-touch-amoled-1.75 \
  --language ru-RU
```

Прошивка **без** `erase_flash` (Wi‑Fi в NVS сохранится):

| образ | адрес |
| --- | --- |
| bootloader | `0x0` |
| partition-table | `0x8000` |
| app | `0x20000` |
| assets | `0x800000` |

USB — порт платы, драйвер CP210x/CH340 по комплектации Waveshare.

## 4. Wi‑Fi (первый boot)

1. Включите плату. Если SSID ещё нет → экран **Wi‑Fi**: точка `Xiaozhi-XXXX`
   (на экране / телефоне может выглядеть как «Syoji …» — это она).
2. Телефон → подключиться к этой точке → браузер **http://192.168.4.1**.
3. Выберите домашнюю сеть **только 2.4 ГГц**, введите пароль.
4. Плата попробует подключиться (~до 60 с). Успех → часы / глаза.
   Неудача → снова hotspot (часто пароль или 5 ГГц).

### Если крутит «настройка → часы → снова настройка»

ESP32-S3 **не умеет Wi‑Fi 5 ГГц**. Нужна сеть 2.4 ГГц:

- в роутере включите 2.4 / сделайте гостевую `MyWiFi-24` на 2.4;
- или временно раздайте 2.4 с телефона и укажите её в форме;
- пароль без «умных кавычек», длина обычно 8+ символов;
- от телефона к точке Xiaozhi лучше отключить VPN.

Позже: **свайп ↓** (шторка) → «Сброс Wi‑Fi», или длинное **BOOT ~3 с**.

---

## 5. Привязка к xiaozhi.me

1. Убедитесь, что Wi‑Fi есть (шторка покажет SSID).
2. В консоли xiaozhi.me нажмите «добавить устройство» → код.
3. Скажите «Валера» **или** короткое BOOT → устройство покажет/озвучит код (как в стандартном XiaoZhi).
4. Введите код на сайте → устройство появится в списке.

## 6. Жесты на экране (после прошивки)

| Жест | Действие |
| --- | --- |
| Свайп **вниз с верха** | Шторка настроек (как у телефона): яркость, громкость, Wi‑Fi, тема, Always On |
| Свайп **вверх** по шторке | Закрыть |
| Свайп **← / →** | Idle: часы ↔ погода ↔ глаза ↔ слайды |
| Тап по строке шторки | Шаг яркости / громкости / смена темы / сброс Wi‑Fi |
| «Валера» | Listen → Think → Speak |
| BOOT короткое | Старт/стоп разговора (запасной) |
| PWR короткое | Wake + громкость +10 |

Плавность: LVGL ~60 fps (`timer_period_ms = 16`), шторка тянется пальцем и доезжает пружиной (~220 мс).

---

## 7. Темы

В шторке тап **Тема** циклит: Modern → Neon → Soft → Retro → Digital.  
Или голосом/MCP: `self.valera.clock_style` с `look` 0…4.

---

## 8. Радио

Пресеты РФ в прошивке. Скрыть нерабочую:

- MCP `self.valera.radio_hide` (index)
- Восстановить: `self.valera.radio_restore`

Декод потока на экране — донастройка после железа.

## 10. Если wake «Валера» капризничает

Обучение на устройстве **не нужно** — шаблоны вшиты.  
На живом голосе можно подкрутить порог DTW в исходниках.  
Пока не сработало — короткое BOOT. Когда Espressif выпустит `wn10_ru_valera`, можно перейти на WakeNet.
