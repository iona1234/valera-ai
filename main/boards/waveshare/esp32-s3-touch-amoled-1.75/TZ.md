# ТЗ Valera · Waveshare ESP32-S3-Touch-AMOLED-1.75

Единственная целевая плата: **1.75** (не 1.75c). Устройство приедет ~через 3 дня.

## 1. Визуал

- Красивее Popka: скругления вместо «топора», единый design-language.
- Прокрутка как на современных часах (scale→0.6, α² у края круга).
- Круговой эквалайзер звука (лучи / рот-EQ).
- Центрирование, одинаковые формы, текст на кнопках в одних местах.
- Крупные finger-friendly кнопки (edge pill h≥72).

## 2. Шторка

Свайп сверху вниз: яркость, громкость, Wi‑Fi, тема, Always On, перезапуск Wi‑Fi.

## 3. Темы

Не только dark/light — стили: **Modern / Neon / Soft / Retro / Digital**.
Память: только палитры + zoom (без новых шрифтовых ассетов).

## 4. Карта экранов

Визуальная схема: главный idle слева, свайпы ←/→/↓, меню радио/галерея/Wi‑Fi/слайд-шоу.

## 5. Wake «Валера»

Локальный `USE_VALERA_RU_LOCAL_EAR` (бесплатно). Обучение на устройстве не требуется —
шаблоны уже вшиты; порог DTW можно подкрутить на живом голосе.
Консоль [xiaozhi.me](https://xiaozhi.me): регистрация **бесплатна** для личных пользователей
(Qwen realtime). Seeed — производитель/магазин плат; отдельная платная подписка
для wake «Валера» **не нужна**.

## 6. Радио

Удаление нерабочих станций из списка (NVS hide-mask + MCP).

## 7. Слайд-шоу

Несколько маленьких «слайдов» с эффектами. На устройстве — процедурные
градиентные слайды (0 байт картинок во flash); превью — то же + лёгкие паттерны.

## Статус исполнения

| # | Пункт | Статус |
| --- | --- | --- |
| 1 | Визуал (скругления, скролл, EQ, кнопки) | Превью + LVGL face; железная проверка после прихода платы |

| 3 | Темы Modern/Neon/Soft/Retro/Digital | MCP `clock_style` look 0–4, NVS |
| 4 | Карта экранов | `ui-preview.html` + `14-map.webp` |

| 7 | Слайд-шоу | Idle `kSlides` процедурно (0 байт картинок) |

### Seeed / Xiaozhi

- **Seeed** — магазин/производитель железа (SenseCAP и т.п.), не биллинг wake-слова.
- Консоль **[xiaozhi.me](https://xiaozhi.me)** (Сиоджи): регистрация для личных устройств **бесплатна**.
- Wake «Валера» в этой прошивке — `USE_VALERA_RU_LOCAL_EAR` (MFCC+DTW), **без облачной оплаты**.
- Обучение на устройстве не нужно; на живом голосе может понадобиться подкрутка порога DTW.
